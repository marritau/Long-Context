\section{Experimental Setup}

\paragraph{Datasets.}
The controlled block uses RULER and NoLiMa. The real QA block uses Qasper,
HotpotQA, and MultiHop-RAG. LIBRA is planned as an optional Russian extension.

\paragraph{Models.}
The main local model is Qwen2.5-7B-Instruct. Phi-3-mini-128k-instruct is a
lighter long-context option. Gemma 2 9B can be used as a short-context control.

\paragraph{Baselines.}
The baseline matrix includes first-B, last-B, first-last, full context, BM25,
dense retrieval, hybrid RRF, hybrid reranking, LongLLMLingua, and Self-Route.

\paragraph{Metrics.}
Metrics include exact match, token F1, evidence recall, evidence precision,
evidence F1, compression ratio, cost-normalized score, position sensitivity
index, middle drop, all-hop recall, and partial-hop recall.
