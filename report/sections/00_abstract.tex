\begin{abstract}
This work studies whether long-context LLM performance can be improved without
changing model weights by optimizing context selection, compression, and
ordering. We propose PEARL, a position-aware evidence assembly method for
long-context QA under fixed token budgets. The planned evaluation compares full
context, truncation, retrieval, compression, and PEARL variants on controlled
and real long-context benchmarks.
\end{abstract}
